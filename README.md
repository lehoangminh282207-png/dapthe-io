# DAPTHE.IO — FC Online Đập Thẻ & Mồi Thẻ Demo

> **"ĐẬP THẺ. GHI DÂY. CHƠI THÔNG MINH."**

Website hoàn chỉnh chạy trực tiếp trên GitHub Pages.

## 🚀 Chạy Demo
- Mở file `index.html` trực tiếp trên trình duyệt, hoặc
- Bật **GitHub Pages** (Settings -> Pages -> Deploy from branch main) để có link demo online.

## ⚡ Tính Năng
- 🎯 Mồi thẻ theo dây & Phát hiện dây trùng theo thời gian thực (Real-time Matching).
- 🗃 Kho dây mồi cộng đồng & Chi tiết chuỗi mồi.
- ⚡ Bộ tính toán tỷ lệ đập thẻ (+1 đến +13).
- ⚽ Tra cứu cầu thủ & Xây dựng đội hình trên sân bóng.
- 📊 Thống kê cộng đồng & Hồ sơ điểm Trust Score.
